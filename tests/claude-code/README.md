# Tests Claude Code — ai-assisted-sustainable-it

Tests automatisés du skill ecocode avec Claude Code CLI en mode headless.

```bash
./run-skill-tests.sh
./run-skill-tests.sh --verbose
./run-skill-tests.sh --test test-ecocode-bootstrap.sh
```

Les tests rapides vérifient le bootstrap `SessionStart` et la description du
skill ecocode.
